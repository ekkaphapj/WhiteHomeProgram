# The White Home — ระบบบริหารที่พัก

เว็บแอปสำหรับโรงแรม/อพาร์ตเมนต์ The White Home Udon Thani — ใช้งานบนมือถือได้ดี (PWA) ทำงานบน Cloudflare Workers + ฐานข้อมูล D1 ทั้งหมด

**URL ใช้งานจริง:** https://thewhitehome.ekapap-j.workers.dev

## ความสามารถ

- 🏠 **หน้าแรก** — สรุปวันนี้ (เข้าพัก/ออกพัก/ห้องว่าง/รายรับ) รายรับ-รายจ่าย-กำไรเดือนนี้ ค่าเช่าค้างเก็บ และกราฟ 6 เดือน
- 🌙 **รายวัน** — บันทึกการเข้าพักรายวัน, ตารางห้องแสดงสถานะทุกห้อง, รับเงิน/ออกพัก/ยกเลิก (เงินที่รับเข้าสมุดรายรับอัตโนมัติ)
- 🔑 **รายเดือน** — ผู้เช่ารายเดือน, ออกบิลทุกห้องในคลิกเดียว, เก็บค่าเช่า+ค่าน้ำ+ค่าไฟ, ประวัติการชำระ, ปิดสัญญา
- 💰 **รายรับรายจ่าย** — บันทึกด้วยมือได้ + รายการอัตโนมัติจากการเข้าพัก/ค่าเช่า (แก้/ลบรายการอัตโนมัติไม่ได้ ต้องแก้ที่ต้นทาง)
- 📊 **รายงาน** — สรุปรายเดือนแยกหมวด, กำไรสุทธิ, สรุปรายวัน, ดาวน์โหลด CSV เปิดใน Excel ได้
- ⚙️ **ตั้งค่า** — เพิ่มห้อง (ทีละห้องหรือเป็นช่วง เช่น 101–105), จัดการบัญชีผู้ใช้ (เจ้าของ/พนักงาน)

## เทคโนโลยี

- **Backend:** Cloudflare Workers + Hono (TypeScript), JWT cookie, PBKDF2
- **Database:** Cloudflare D1 (SQLite) — migrations ใน `migrations/`
- **Frontend:** React + Vite + Tailwind CSS v4 + TanStack Query + Recharts
- **PWA:** manifest + service worker — เปิดผ่าน Chrome บนมือถือแล้วกด "เพิ่มไปยังหน้าแรก" ได้เลย

## คำสั่งหลัก

```bash
npm install            # ติดตั้งครั้งแรก
npm run dev            # dev server ท้องถิ่น (http://localhost:5173)
npm run db:migrate:local   # สร้างตารางในเครื่อง
npm run build          # build  production
npm run deploy         # build + ขึ้น Cloudflare
npm run db:migrate:remote  # apply migrations ฐานข้อมูลจริง
npm run typecheck      # ตรวจ TypeScript
```

## เริ่มใช้งานครั้งแรก

1. เปิด URL → ระบบจะพาไปหน้า "ตั้งค่าระบบครั้งแรก" ให้สร้างบัญชีผู้ดูแล (admin)
2. ไปที่แท็บ ⚙️ ตั้งค่า → เพิ่มห้องพัก (แนะนำ "เพิ่มหลายห้อง" เช่น 101–105 พร้อมใส่ราคารายวัน/รายเดือน)
3. เริ่มบันทึกได้เลย — แท็บรายวันสำหรับแขกค้างคืน, แท็บรายเดือนสำหรับผู้เช่า

## หมายเหตุ

- ข้อมูลแต่ละสภาพแวดล้อมแยกกัน: ทดสอบในเครื่อง (`.wrangler/state`) ไม่เกี่ยวกับข้อมูลจริงบน Cloudflare
- JWT secret เก็บเป็น Worker secret (`wrangler secret put JWT_SECRET`) — เปลี่ยนได้ตลอด
- D1 มี Time Recovery ย้อน 30 วันในตัว และแนะนำกด Export CSV ท้ายเดือนเก็บสำรองเพิ่ม
- โดเมนเอง/custom domain เพิ่มได้ภายหลังใน Cloudflare Dashboard
